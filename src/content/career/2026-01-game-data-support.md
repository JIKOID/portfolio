여러 라이브 게임과 신작의 데이터 분석 요구사항을 대시보드와 데이터 파이프라인으로 지원하고 있습니다.

- 확률형 아이템 데이터 집계·대시보드 구축, 게임물관리위원회 대응 데이터 준비, 대형 인게임 이벤트 데이터 처리
- 주요 라이브 게임들의 지표 대시보드 설계 및 데이터 이슈 대응
- 신규 게임 12종 이상 런칭 지원: 대시보드 구축 → 이벤트/퍼널 로그 검증 → 소프트 런칭 데이터 초기화
