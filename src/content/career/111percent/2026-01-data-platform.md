일간 약 1억 건, 월간 약 2TB의 데이터를 수집하는 BigQuery 기반 데이터 웨어하우스와 게임 데이터 파이프라인을 운영했습니다.

### 담당 업무
- Airflow 배치 스케줄링 및 게임 이벤트 로그 설계·수집 파이프라인 운영
- 게임 배포 시 메타데이터 동기화 파이프라인 운영
- Firestore 백업 → GCS 업로드 → BigQuery 적재 파이프라인 운영
- 이벤트 로그 수집 오류 처리를 위한 Pub/Sub 데드레터 구독 생성·연동
- BigQuery 예약 쿼리 기반 준실시간 지표 집계에서 Append를 Merge로 전환해 멱등성 확보

### 운영 이슈와 해결
- **BigQuery 예약 작업 중복 실행 (2026.02):** 알려진 이슈를 확인하고, 재실행되어도 중복 데이터가 쌓이지 않도록 Merge 기반으로 쿼리 변경
- **Airflow 원격 로그 누락 (2026.02):** 로그가 GCS 대신 컨테이너 내부에만 저장되던 서비스 계정 연동 오류를 찾아 재설정
- **google-cloud-storage 버전 변경 (2026.02):** 2.10.0에서 3.0으로 변경하며 발생한 체크섬·스트림 타입 문제를 StringIO → BytesIO 전환으로 해결
- **DAG 실행 결과 감지 실패 (2026.03):** DAG 간 logical_date 차이로 센서가 실행 결과를 감지하지 못하는 문제를 execution_date_fn으로 대상 실행 시간을 지정해 해결
