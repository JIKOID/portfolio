게임 내 확률 콘텐츠 11종의 실측 데이터를 분석하고, 유저에게 공개되는 확률 정보의 집계 파이프라인과 데이터 마트를 구축했습니다.

### 담당 업무
- 확률 콘텐츠 11종의 데이터 분석 및 표시 확률과의 정합성 검토
- 기존 이벤트 로그로 집계할 수 없는 케이스의 로그 스펙 설계·제안
- 디멘전·팩트 테이블로 분리한 데이터 마트 스키마 설계
- 확률 데이터 가공·적재 일 배치 파이프라인 구축 및 자동화

### 성과
- 실측 확률 검증 결과를 유저 노출 페이지에 연동하고 대외 공개 확률 정보의 데이터 소스 담당
- 제안한 이벤트 로그 스펙의 클라이언트 반영으로 11종 전체의 집계 커버리지 확보
- 11종을 단일 디멘전·팩트 스키마에 수용해 새로운 확률 콘텐츠가 추가되어도 마트 구조 변경 없이 확장 가능하도록 설계
