이벤트 로그에 installation_id 공통 프로퍼티를 도입하면서 수집 서비스, 웨어하우스 스키마, 적재 파이프라인과 기존 데이터 백필을 함께 변경했습니다.

### 설계와 구현
- GitLab CI 기반 프로퍼티 추가·배포 절차를 확인하고 개발 환경 수집 코드와 테이블 컬럼 변경
- 테스트용 Cloud Run Function에서 신규 프로퍼티 수집을 검증한 뒤 운영 수집 서비스를 신규 서비스로 전환
- 이벤트 로그 테이블에 installation_id 컬럼을 추가하고 적재 파이프라인 수정
- 해당 기능이 배포된 게임의 기존 이벤트 로그 백필

### 검증과 운영 전환
- QA 빌드의 패키지 누락을 발견해 재빌드를 요청하고 앱 업데이트·재설치 시나리오로 수집 검증
- 설치 이벤트 발생 흐름을 문서화하고 배포 알림 채널 정비
- 백필 이후 모니터링에서 이상 없음을 확인해 운영 전환 검증 완료
