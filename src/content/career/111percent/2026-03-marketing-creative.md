AppsFlyer MMP API와 Data Locker를 활용해 광고 소재 정보와 KPI·매출 코호트 데이터를 통합 수집하는 파이프라인을 구축했습니다.

### 담당 업무
- 마케터의 수집 요구사항을 정리하고 개별 관리하던 광고 소재 정보 수집
- AppsFlyer API로 광고 소재 KPI 데이터 수집
- Data Locker 데이터를 활용해 매출 코호트 데이터 가공
- 광고 소재별 KPI·설치·구매·매출 코호트 집계 및 데이터 마트 생성
- Looker Studio 데이터 소스 연동

### 성과
- 개별 관리되던 광고 소재 정보를 100% 통합 관리 체계로 전환
- AppsFlyer 대시보드 수치 대비 집계 데이터 정합성 98% 검증
- 수작업 다운로드·집계를 자동 집계 체계로 전환

### 운영 개선 (2026.10)
- 광고 소재 제작자 관리를 Airflow Variable로 전환하고 게임별 제작자 정보 추가
- 신규 게임의 소재 리포트에 필요한 데이터 수집 범위 확대
