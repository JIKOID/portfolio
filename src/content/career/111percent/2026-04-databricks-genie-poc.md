Databricks Genie를 활용한 대화형 데이터 분석과 대시보드 구축 가능성을 검증하고, 환경 적합성과 비용을 기준으로 도입 여부를 판단했습니다.

### 준비와 검증
- 신규 게임 데이터 분석 대시보드 구축
- BigQuery → AWS S3 데이터 복제 및 Databricks-AWS 연동·데이터 카탈로그 생성
- 기존 Redash 대시보드와 동일한 구성을 재현해 성능·사용성 비교
- 대화형 에이전트의 차트·대시보드 생성 범위 검증

### 검증 결과
- 카탈로그 생성 과정에서 데이터 확장의 어려움 확인
- 대화형 차트 생성은 가능했으나 대시보드 구축에는 별도 환경이 필요함을 확인
- BigQuery 기반 Google Cloud 환경에서 AWS로 이전하는 비용까지 검토한 뒤 도입하지 않기로 결정
