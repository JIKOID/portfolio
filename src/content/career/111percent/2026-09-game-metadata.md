게임별 아이템·상품 메타데이터를 운영툴과 분석 대시보드에 연동하고, 서로 다른 시트 구조의 공통 항목을 정리해 스키마를 설계했습니다.

### 담당 업무
- 랜덤다이스2의 상품 메타데이터 수집을 개발·QA 환경에 적용하고 연동 테스트 수행
- 상품 테이블과 다국어 텍스트 간 매핑 오류를 확인해 원본 데이터 수정 후 빌드 검증
- Sheep Duck의 상품·재화 시트를 연동하고 운영툴·Redash 반영 확인
- 게임별 Item·ShopProduct 시트에서 공통 값을 정리하고 운영툴 연동 스키마 모델링·문서화
- 운영툴 뷰 테이블을 운영 데이터만 조회하도록 변경하고 개발·QA는 원본 테이블을 직접 조회하도록 분리

### 활용
- 게임별 메타데이터를 운영툴과 대시보드의 아이템 필터에 연결
- 테이블·컬럼 명세를 데이터 분석 에이전트의 게임 지침과 예제 쿼리 보강에 활용
