title: 데이터 마트 마이그레이션 (On-Premise to AWS RDS)
---

온프레미스 DB의 리소스 부족과 유지보수 비용 증가 문제를 해결하기 위해 AWS RDS로 데이터 마트를 마이그레이션했습니다.

- 온프레미스에 적재하던 파이프라인의 DB 엔드포인트를 AWS RDS로 변경, 불필요한 파이프라인·테이블 정리
- 테이블·컬럼 네이밍 컨벤션을 정의하고 일괄 적용
- Redash 데이터 소스를 AWS RDS로 전환하고 변경된 구조에 맞춰 기존 쿼리 수정
- 온프레미스 증설, BigQuery 등 여러 대안을 검토한 끝에 AWS RDS로 결정, 유지보수성과 분석 성능·효율성 향상
