운영 데이터베이스 직접 조회로 인한 서비스 부하 문제를 해결하기 위해 데이터 웨어하우스를 구축했습니다.

- Delta Lake로 운영 데이터를 AWS S3에 일자별 파티션 증분 적재(CDC 역할 겸용)
- 온프레미스 Docker 기반 PostgreSQL로 데이터 웨어하우스 구축, 컨테이너 간 네트워크 연결로 접근 문제 해결
- 온프레미스 Docker 환경의 Airflow로 S3 → 웨어하우스 → 데이터 마트 적재를 자동화, 리소스 조절을 위한 스케줄 조정
- 운영 서비스 부하 100% 제거, 데이터 분석가들이 부담 없이 분석 가능한 환경 제공

### 온프레미스 데이터 인프라 서버 운영
- 온프레미스 데이터팀 서버 운영, Docker 기반 PostgreSQL/Airflow/Spark/Redash/Grafana 구축 및 운영
- 온프레미스 리소스 부족 시 슬랙 경고 알림 설정
