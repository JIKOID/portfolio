기존 파이프라인의 데이터 정합성·신뢰성 문제를 파악하고 데이터 웨어하우스 재구축을 제안·주도했습니다.

- 최소 비용으로 AWS RDS 기반 웨어하우스 설계, 파이프라인 단계 구분 및 데이터 모델링·ERD 설계에 50% 기여
- 테스트 환경에서 PoC 진행 후 이슈 개선, 기존 대비 정합성·신뢰성 향상 확인 후 재구축 진행
- Streamlit 기반 사내 데이터 분석 플랫폼 개발·배포(테이블·그래프 시각화 제공)
- Docker Compose로 Datahub 서버 구축, 스케줄러로 테이블 메타데이터 수집, Github Actions로 CD 스크립트 작성
