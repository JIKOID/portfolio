옥션 사이트 데이터를 수집·가공·적재하는 파이프라인 전 구간을 담당했습니다.

- AWS EMR 환경에서 PySpark Application으로 데이터 가공 및 적재, 파티셔닝·리소스 최적화로 안정적인 분산 처리 구현
- Executor 비정상 종료, 파티션 수 최적화 등 반복적인 시행착오를 거쳐 리소스 관리 노하우 확보
- BeautifulSoup·Selenium 기반 스크래퍼 개발 및 고도화, LangChain·LLM으로 데이터 추출·카테고리화(한국어 번역 정확도 80%+ 확보)
- 데이터 적재 구조를 AWS RDS 직접 적재 방식에서 S3(데이터 레이크) 경유 방식으로 마이그레이션해 데이터 품질과 정합성 향상
