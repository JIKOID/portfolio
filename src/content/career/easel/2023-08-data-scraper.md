옥션 사이트 데이터를 수집하는 Python 스크래퍼를 개발·정상화하고, LLM 기반 추출과 데이터 레이크 도입으로 수집 품질을 개선했습니다.

### 담당 업무
- BeautifulSoup4·Selenium 기반 스크래퍼 개발, 비정상 동작 수정 및 기능 고도화
- 사이트 업데이트로 변경되는 수집 로직과 API 요청 차단 이슈 대응
- LangChain·OpenAI 모델로 데이터 추출·카테고리화, Pydantic으로 데이터 모델 정의
- 프롬프트 엔지니어링을 반복해 한국어 번역 정확도 80% 이상 확보
- AWS RDS 직접 적재에서 S3 데이터 레이크 경유 방식으로 수집 구조 변경

### 성과
가공 전 데이터를 바로 사용하며 발생하던 정합성 문제를 줄이기 위해, S3 저장 후 가공·검증을 거쳐 웨어하우스에 적재하는 단계를 마련했습니다.
